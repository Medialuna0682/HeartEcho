# 新版本与独立 TB 版

本项目是非官方的 QQ 伴侣工具，与《碧蓝航线》官方无隶属关系。TB 形象采用大型作战中的领航员，不使用养成结局性格。没有附带官方图像或语音资源。

## 启动与交付

普通版沿用原启动方式。开发环境可运行 `node index.mjs --tb --tray`，或双击 `启动TB.bat`。TB 默认数据位于 `%LOCALAPPDATA%\心语TB\data`，日志与设置也独立；控制面板默认 5321，OneBot WS/HTTP 默认 3103/3102。它不会自动复制普通版的角色、记忆或密钥。用户显式设置的数据目录环境变量优先。

在 Windows、支持 SQLite FTS5 的 Node 24 上运行 `node tools/package-tb.mjs`，可生成独立的 `dist/HeartEcho-TB` 便携目录，内含构建时 Node 运行时。分发该目录即可，不需要目标电脑另装 Node。QQ 与兼容的 OneBot 协议端须单独准备并在界面中选择；此构建不会复制开发机协议端、登录态、用户文件或 Key。普通版与 TB 如需同时使用同一个协议端，应按实际协议能力配置不同账号和端口。

## 记忆与服务授权

打包时会取得对应 Node 版本的官方完整许可证，因此需要网络；离线构建可用 `HEARTECHO_NODE_LICENSE` 指向已准备的官方许可证文件。本机 Hindsight Key 留空时会在保存本机服务设置时随机生成，之后再确认数据授权。

在“记忆与互动”填写 Hindsight 地址、归档模型、embedding 和 reranker。默认关闭扩展记忆，启用后只有“回忆一下”“回想一下”“还记得”“帮我回忆”等明确请求才召回长期记忆。普通聊天仍使用近期上下文，不自动注入旧的全局日记或置顶事实。

每天整理前一天已结束日期的对话，角色、账号、会话和清空代次分别归档。仅接入本版本后已记录来源的消息会进入新归档，不会猜测旧记录的角色归属并批量上传。服务暂不可用时保留本地每日摘要和数字生命状态，聊天可继续。每次故障状态变化只加入一次角色化说明。

保存设置后，页面会列出接收服务和将传输的数据；明确同意后才向 Hindsight 发送摘要或回忆请求。更换服务地址、模型或凭据会使同意失效。Hindsight 本身会向其配置的模型、embedding、reranker 服务发送抽取/候选数据；若接入自行管理的服务器，须核对服务器的实际下游配置，不要仅凭面板填写项假设远端配置一致。

### 一键启动的前提

已安装并运行 Docker Desktop 后，在面板确认授权，再点“一键启动本机记忆服务”。固定使用 `ghcr.io/vectorize-io/hindsight:1.1.0`，默认回环地址 `127.0.0.1:8888`，启用 Hindsight 内置 API Key 鉴权，不公开其控制台端口。必须设置 Hindsight API Key 和支持结构化输出的归档模型。模型服务使用 OpenAI 兼容接口；外部 embedding 使用 OpenAI 兼容接口，外部 reranker 使用 Cohere 兼容 `/rerank` 接口。API 地址必须填写实际服务要求的完整基础地址。

首次需要网络下载镜像与本地模型，可能耗时较长。运行时使用独立 Docker 命名卷保存 PostgreSQL 数据，并固定 worker ID。Docker 不存在时明确报错，普通聊天继续运行；不会擅自安装 Docker 或申请管理员权限。容器使用 `unless-stopped` 随 Docker 恢复，已授权的心语启动也会尝试拉起服务。已启动的服务独立于心语进程；在面板关闭扩展记忆后心语不再发请求，但不会替用户删除容器和数据卷。

配置变化后不会悄悄重建仍使用旧凭据的容器。请先停止并移除对应容器，再重新启动，保留命名卷以保留数据。不要删除数据卷，除非明确希望物理删除全部外部记忆。

### 权限与删除

启用扩展记忆后，旧的自动会话归档和混合日记定时器暂停，改用按来源分别生成的每日摘要；数字生命状态与关系机制继续工作。清空仅删除当前角色和账号的数据，其他角色已知来源的数据保留；清空水位会阻止旧共享资料重新进入被清空的角色会话。

共享角色/群以成对 ID 配置，默认均为空。群内容可以在同一人的私聊中使用；不同群默认隔离，开启指定群共享后也只在该用户明确要求回忆时使用其自己会话来源的内容。

私人内容进入群聊须内容所属者在私聊发送 `授权记忆到群 群号`，撤销用 `撤销记忆到群 群号`。群里提到话题不能代替授权。角色共享由软件管理者开启，但不能替其他人授权私人内容。权限在召回前、结果返回后和实际回复前校验；服务不能跨银行自行扩大召回范围。

面板可以查看、修改和删除每日摘要。修改会轮换远端 bank，删除/清空会话立即使旧内容不可召回。远端物理删除在服务在线且当前凭据与接收方匹配时重试；若已更换服务器，旧服务器上可能仍保留副本，需要恢复对应配置后删除或由服务器管理员处理。日志、备份和外部供应商留存仍按原数据治理边界处理。

## 输入、戳一戳和额度

私聊静默等待范围 1～15 秒，新消息重置静默计时，但从第一条未回复消息起的整轮等待上限不超过 15 秒。QQ 输入状态只能延长到该上限，没有待回复内容时不会凭空发言。未收到协议端输入事件时只使用静默等待。模型生成与网络投递耗时不包括在收集输入的等待上限内，已经开始的模型请求当前仍不物理取消。

戳一戳默认仅私聊启用，角色可选择固定文字或人设生成；可指定某群覆盖，也可恢复继承。连续事件受独立冷却限制。仅响应戳向当前机器人账号的事件。

群总额度与成员额度支持滚动分钟/小时/24 小时窗口，任一个先耗尽即停止普通回复。个人在不同群分别计数，角色也分别计数；@、戳一戳、欢迎不扣普通额度，但仍受冷却、暂停、黑名单及模型预算约束。升级后使用新计数桶，旧频率计数不迁移。耗尽同一桶和周期只提示一次。

软件管理者可以在面板重置额度或管理豁免。允许 QQ 群管理员管理的开关默认关闭，启用后需 @机器人发送 `重置额度 QQ号`、`豁免额度 QQ号` 或 `取消豁免 QQ号`，心语会通过协议端查询其实际管理员身份。

## TB 搜索与群规

TB 普通群消息只在被 @ 时回复；戳一戳、欢迎和主动消息仍按各自开关，私聊遵循对话设置。默认国服；缺少目标玩法等配队必要条件先追问。默认直接访问碧蓝 Wiki，不需要搜索 Key。自定义搜索接口接收 POST JSON `{query,max_results}`，返回 `{results:[{title,url,content,published_date}]}`，Key 使用 Bearer；保存后单独同意查询文本传输。不会自动转发聊天历史或附件。

参考资料作为不可信数据使用，不执行网页内指令。回答列出实际取得的来源和日期；没有取得资料或搜索关闭时明确标注未联网核实，不编造引用。检索日期不代表资料适用于当前版本；资料不足时应说明，不能承诺任何配队一定最优。

群规默认来自最新一条公告，也可指定公告 ID 或手写文字。先保存群设置，再检查公告；公告变化会在面板等待软件管理者确认，不会立即替换群规。新成员在短窗口内合并欢迎，发送已确认文字。协议端不支持读取公告时可用自定义文字。
